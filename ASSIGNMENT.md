# 📄 The Basics of HTML

Practice common HTML elements and attributes by marking up four starter pages with
headings, paragraphs, lists, images, figures, and links.

## 🎯 Overview

In this coding exercise, you will keep practicing the basic structure of an HTML page
while learning many of the common HTML elements and attributes you will use throughout the
course.

Last week, you created your first simple HTML page. This week, you will build on that
foundation by working with headings, paragraphs, lists, inline elements, images, figures,
captions, and links.

The pages you create in this exercise will look plain in the browser. **That is expected.**
Right now, the focus is on using HTML to give content structure and meaning. Soon, you will
use CSS to control the visual design, including colors, fonts, spacing, and layout.

> [!IMPORTANT]
> **The companion videos for this exercise are in Canvas**, on the assignment page. They
> walk you through every step, so watch them there instead of working from this file
> alone.

## 🧠 What You Will Learn

By completing this exercise, you will practice how to:

- Open a full project folder in Visual Studio Code
- Use the basic HTML document structure
- Use heading elements based on structure and importance
- Mark up paragraphs, lists, abbreviations, line breaks, emphasized text, strong text,
  highlighted text, and superscript text
- Add images using the `img` element
- Use attributes such as `src`, `alt`, `href`, `title`, and `target`
- Create figures and captions using `figure` and `figcaption`
- Create links to websites and files
- Preview your work in a browser

## ✅ Before You Submit

Check the following:

- [ ] Each HTML file has the basic HTML document structure
- [ ] Each page has a useful `title` element in the `head`
- [ ] All visible page content is inside the `body` element
- [ ] Headings are marked up with appropriate heading elements
- [ ] Paragraphs are marked up with `p` elements
- [ ] Lists use `ol` or `ul`, with each item inside an `li` element
- [ ] Images display correctly in the browser
- [ ] Images include useful `alt` text
- [ ] Links are clickable and go to the correct location
- [ ] You saved all of your files

## 🛠️ Troubleshooting

If something is not working, check these common issues first:

- Did you save the file?
- Is the file name spelled correctly?
- Is the file extension correct?
- Is the image or linked file in the correct folder?
- Did you accidentally move or delete a starter file?
- Is your visible page content inside the `body` element?
- Are your opening and closing tags in the correct places?
- Are there quotation marks around your attribute values?

**Having problems with the videos?**

- **Getting a warning about third-party cookies?** Try using Chrome. Safari's default
  security settings may prevent embedded Canvas videos from playing unless those settings
  are changed.
- **Getting an "Access Denied" error?** Refresh your browser. In many cases, the videos
  will load correctly after the page reloads.
