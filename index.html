The Basics of HTML What is HTML? HTML stands for HyperText Markup Language. It acts as the foundation for documents designed to be displayed in a web browser. Good HTML structure is based on logic, order, and using semantically correct markup. If you have a heading use a heading element. If you have a paragraph, use a paragraph element. If you have a list, use a list item element. If you’re quoting a few lines, use a blockquote element. Those elements provide meaning to the content, making them semantically correct, in addition to being solid HTML structure. Once your HTML structure is in place with the appropriate markup, add CSS for visual presentation. Start with good HTML structure and then add the CSS for the visual presentation that you have in mind. HTML determines the organizational structure and meaning of the content on a web page, but doesn't define how it should look or where it should be located on the page. CSS determines the style, appearance, and location of the content. HTML Document Structure !DOCTYPE html head body The <!doctype> declaration is used to instruct web browsers which version of HTML is being used and is placed at the very beginning of the HTML document. Next comes the <html> element, which represents the root (top-level element) of an HTML document. All other elements must be contained inside the <html>. The <head> is used to add meta data, the page's title, and links to external CSS and JavaScript files. The elements contained in the <head> are mostly used for adding background information to help the browser. The <body> contains all the content of a web page, such as headings, paragraphs, images, hyperlinks, tables, lists, etc. Put everything you want to be visible in the browser window within the <body> of your page. HTML Syntax Elements Elements define and give structure to the objects on your page. You should always choose an element based on its semantic meaning, not the way it looks in a browser. You can use CSS to make any element look the way you want so ignore its default appearance. Tags Elements are often made of multiple sets of tags, identified as opening and closing tags. Opening tags mark the beginning of an element, such as <div>. Closing tags mark the end of an element and begin with a forward slash, such as </div>. Attributes Attributes are properties used to provide additional instruction to an element. More commonly, attributes are used to assign an id, class, or title to an element, or to give media elements a source (src), or to provide a hyperlink reference (href).
