Hyperlinks Links to other pages are created with the <a> element and the href attribute. The value of the href attribute is the page that you want people to go to when they click on the link. Users can click on anything that appears between the opening <a> tag and the closing </a> tag and will be taken to the page specified in href. Absolute Links When you link to a completely different website you must use an absolute URL. That means the value of the href attribute will start with http:// and include the full web address for the site. This is a link to the University of Cincinnati web site Relative Links When you are linking to other pages within the same site, you do not need to specify the full domain name in the URL. You can use a relative URL which only contains the directions relative from this page to the one you are linking to. An e-mail link will automatically launch the default mail program configured for the browser. The href value of an e-mail link starts with mailto: followed by the e-mail address. You should avoid opening links in a new window if they're going to a different page within the same site. Only use it when sending someone to a compltely different web site.
