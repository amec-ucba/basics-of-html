Common Building Block Elements Headings There are six levels of headings, h1 is the most important and h6 is the least. Use the levels consistently throughout your site to give a logical hierarchy or outline to a document. Choose a heading based on its importance, not sequential order or visual size. Paragraphs Paragraphs are the most rudimentary elements of a text document. They can contain text, images, or other inline elements. By default they add space below the closing tag. Most of the content of my page will be contained within a paragraph tag. Notice the font that this is being shown in. It is the DEFAULT font, chosen by your browser (usually Times New Roman). I can change this with CSS. Lists This is an ORDERED list It has numbers generated by the browser I can change the list properties with CSS This is an UNORDERED List It has bullet points No order implied, just a bunch of different points we want to make Abbreviations Use <abbr> to indicate when something is an abbreviation. You should add the title attribute to spell out the full term. This is a handy way to write UCBA but still include the entire name of the college. The information you include in the title will appear when you hover your cursor over the element. Line Break The <br> element produces a line break in text (carriage-return). It is useful for writing a poem or an address, where the division of lines is significant. It should only be used inside block-level elements, NOT as a way to add space above or below and element. It's also one of those weird elements that doesn't have a closing tag. So I can have text like this A Few More Elements That Add Semantic Meaning Older versions of HTML included tags like <b> for bold and <i> for italic. Those elements added a particular visual look but they didn't add any semantic meaning. HTML5 added new elements that are about the context instead of the appearance. <strong> is for content that is of "strong importance" that you want to greatly emphasize. This could be an entire sentence or a single word that is of greater importance compared to nearby content. The default appearance is to make the text bold, but I can use CSS to make it look any other way I want. <u> represents a span of text which should be rendered in a way that indicates that it has a non-textual annotation. This is rendered by default as a simple solid underline, but that can be changed with CSS. <mark> indicates text which is marked or highlighted for reference or notation purposes, due to the marked passage's relevance or importance. <sup> specifies text to be displayed as superscript, which appears half a character above the regular line and rendered a little smaller than the rest of the text.
