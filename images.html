Images The image element <img> embeds a graphic file in a webpage. The element is unusual because it only has an opening tag and doesn't have a closing tag. It has to include a src attribute to let it know it can find the image file. This will usually be a relative URL pointing to an image on your own site. The alt attribute is strongly recommended because it provides a description of the image for search engines and screen readers. Web pages can diplay the following types of image files: .jpg, .png, .gif, .svg, .webp, .apng, .avif You should save the image file at the same width and height it will appear on the web page. Even though you can resize an image using the width and height attributres, if the image file is different than the size you indicate it can get distorted. Adding a Caption to an Image The <figure> element is a container to hold both an image and its associated caption, which is specified using the <figcaption> element. The figure, its caption, and its contents are referenced as a single unit instead of separate unrelated elements.
